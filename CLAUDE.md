## Planned architecture (docs/ARCHITECTURE.md)

- Monorepo (npm workspace today; pnpm + Turborepo planned): `apps/{worker,admin}`, `packages/supabase`, `supabase/{migrations,functions,tests}`; `packages/shared` and `ui-native` are planned, not created.
- **Business rules live in the database, not the apps.** The job lifecycle is a state machine enforced by one SQL function (RPC) per transition; each checks caller role + current status, updates, and writes the audit log in one transaction. Quote totals are computed server-side.
- pg_cron handles stuck-job flagging, review reminders and job expiry (open jobs expire after 24 hours). Edge Functions only for what SQL cannot do (push via FCM, the admin emailed code). Auth OTP is Supabase Auth (phone + WhatsApp/SMS via Twilio) for workers.
- Storage: private buckets (`identity`, `job-media`, `worker-media`, `report-media`), signed URLs only. Schema changes only as migration files (never edit an existing one, never edit a hosted database by hand).

## Product decisions that are easy to get wrong (docs/DECISIONS.md)

- Customer and worker accounts are separate. Worker sign-in is phone + OTP (six digits); email sign-in is removed from the worker app. Admin sign-in is email + password + emailed code.
- Matching is by category + DHA phase (1 to 8); no GPS. Workers and residents are both verified manually by DHA staff (Approve / Visit HQ / Reject). Worker documents: CNIC, police certificate, photo (no licence). Resident: CNIC + utility bill.
- Job statuses: `draft, open, interested, quoted, accepted (unused), scheduled, in_progress, completed, cash_collected, reviewed`, plus `disputed`, `cancelled`, `expired`. Quote revisions are MVP 2. A rejected worker cannot re-quote the same job.
- Resident phone and plot number are hidden until a quote is accepted. Voice notes are in the MVP. A worker can have several categories; eight categories, stored in the database. Reports allowed from `scheduled` until 7 days after completion (the windows are settings); outcomes no action / warning / suspend; staff job cancellation is a separate action; no refunds.
- Ratings are customer to worker only. "Report a problem" and "I feel unsafe" exist in both apps; helpline 1092. Commission, manual assignment by staff, direct booking and chat are out of scope for the MVP.
